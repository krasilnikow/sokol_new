# СОКОЛ — редизайн сайта

Современный редизайн сайта sokolsecurity.ru: React 19 + TypeScript + Vite + Tailwind CSS 4 + React Router + Framer Motion.

## Структура

- `src/pages` — страницы: главная, услуги (список и детальная), о компании, контакты, 404
- `src/components` — переиспользуемые блоки (шапка, подвал, карточки услуг, формы и т.д.)
- `src/data` — контент сайта (реквизиты компании, описания услуг) — правьте тексты здесь
- `src/index.css` — тема оформления (цвета, шрифты) через Tailwind `@theme`

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173`.

## Сборка для продакшена

```bash
npm run build
npm run preview   # проверить собранную версию локально
```

Готовая статика появится в папке `dist/` — её можно разместить на любом хостинге.

## Что редактировать

- Телефоны, адрес, email, часы работы — `src/data/company.ts`
- Тексты и состав услуг — `src/data/services.ts`
- Форма обратной связи (`src/components/ContactForm.tsx`) сейчас открывает письмо через `mailto:`. Чтобы заявки уходили напрямую на сервер, подключите свой backend или сервис вроде Formspree/Getform.
- Карта на странице «Контакты» — `src/pages/Contacts.tsx` (сейчас встроена карта Яндекса по адресу офиса).
